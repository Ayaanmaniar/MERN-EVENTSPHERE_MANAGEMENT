# Demo video script (≈ 6 minutes)

The brief asks for a video of the complete working of the application. Record your screen (OBS / Windows Game Bar `Win+G`) while following this script after running `npm run seed`.

1. **(0:00)** Show `npm run dev`, open <http://localhost:5173>. Briefly explain the 3 roles.
2. **(0:30) Sign-up & password reset** — register a new attendee (consent box), log out, use *Forgot password* and set a new password.
3. **(1:15) Organizer** — log in as `admin@eventsphere.com`. Dashboard → create an expo → *Booths & schedule* → generate floor plan → add two sessions.
4. **(2:15) Exhibitor** — log in as `tech@eventsphere.com`: edit profile & logo, apply to the new expo with a document.
5. **(3:00) Approval** — back as organizer: *Applications* → approve (note the exhibitor notification).
6. **(3:20) Booth selection** — as exhibitor: *My Booth* → reserve on the floor plan → add booth details/staff.
7. **(4:00) Attendee** — log in as `ali@eventsphere.com`: register for expo, browse exhibitors (search/filter), click booths, register + bookmark sessions, chat with an exhibitor.
8. **(4:45) Real-time** — keep the attendee page open, edit a session as organizer: attendee sees the update and a notification instantly.
9. **(5:15) Reports** — organizer *Reports*: engagement, booth traffic, session popularity, export CSV. Show *Feedback*.
10. **(5:45)** Show *My account → Download my data*, then wrap up.
